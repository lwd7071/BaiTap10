# Bài tập JWT

Hai project demo cùng chức năng, khác thư viện ký/xác thực JWT:

- `JWT-JJWT`: JJWT 0.12.6.
- `JWT-Nimbus`: Nimbus JOSE + JWT 10.10.

Cả hai thống nhất API response envelope, validate input, có UI đăng nhập/đăng ký và hồ sơ. Chạy `JWT-DB-Seed.sql` trong SQL Server Management Studio để tạo DB và tài khoản demo `demo / JwtDemo123!`. Hướng dẫn test nằm trong README từng project.
