# Bài tập JWT

Hai project độc lập để làm cùng bài demo trong bài giảng:

- `JWT-JJWT`: JJWT 0.12.6.
- `JWT-Nimbus`: Nimbus JOSE + JWT 10.10.

Cả hai có UI đăng nhập/đăng ký và hồ sơ, các API JWT được bảo vệ, cùng cấu hình SQL Server. Chạy `JWT-DB-Seed.sql` trong SQL Server Management Studio để tạo database và tài khoản demo `demo / JwtDemo123!`. Mỗi project README có hướng dẫn cấu hình, chạy và kiểm tra API.
